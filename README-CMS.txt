TENT4RENT PAGES CMS - UPUTE

1. U GitHub repozitoriju tent4rent-website odaberite Add file > Upload files.
2. Prenesite sadržaj OVE mape u korijen repozitorija (i skrivenu .pages.yml!). Zamijenite postojeće datoteke.
3. Provjerite da postoje .pages.yml, data/site.json, assets/tent4rent-logo.png i ostale datoteke.
4. Nakon GitHub Commit changes otvorite app.pagescms.org.
5. Otvorite projekt i opciju Tent4rent - sadržaj stranice.
6. Uredite polja i pritisnite Save. Cloudflare Pages automatski ažurira stranicu.
7. E-mail obrazac otvara zadani e-mail program; nije pravi serverski obrazac.
8. Dok e-mail nije unesen, obrazac ne šalje upit.
9. Za galeriju učitajte fotografije u polja slike (putanja /assets/...).
10. Uređivanje naslova mijenja tekst ali ne omogućuje složeno slaganje novih odjeljaka.
